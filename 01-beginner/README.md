# Stage 1: Beginner

The foundations of Python. No prior programming experience needed. Work through the
notebooks in order; each one builds on the last.

## Lessons

| # | Notebook | You will be able to |
|---|----------|---------------------|
| 1 | `01_getting_started.ipynb` | Run code in Jupyter, print output, write comments, and read an error message |
| 2 | `02_variables_and_types.ipynb` | Store values in variables and work with `int`, `float`, `str`, and `bool` |
| 3 | `03_numbers_and_math.ipynb` | Use the arithmetic operators and control the order of operations |
| 4 | `04_strings.ipynb` | Build text with f-strings, slice it, use string methods, and read input |
| 5 | `05_making_decisions.ipynb` | Compare values and branch with `if` / `elif` / `else` |
| 6 | `06_loops.ipynb` | Repeat work with `for` and `while`, and control loops with `break` / `continue` |

## How to work through a notebook

Read each section, run the example cells with **Shift + Enter**, and change them to see
what happens. Do the **Practice** section yourself before looking at the
**Practice Solutions** at the bottom.

When you can complete the practice in every notebook without peeking, move on to
`02-intermediate`.
