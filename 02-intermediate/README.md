# Stage 2: Intermediate

Collections, code organisation, and working with files. This stage assumes you have
finished the beginner stage. Work through the notebooks in order.

## Lessons

| # | Notebook | You will be able to |
|---|----------|---------------------|
| 1 | `01_lists.ipynb` | Build and edit lists, slice them, nest them, and avoid the copy trap |
| 2 | `02_dictionaries.ipynb` | Store and look up data as key/value pairs |
| 3 | `03_sets_and_tuples.ipynb` | Use sets for unique items and tuples for fixed groups |
| 4 | `04_comprehensions.ipynb` | Build lists and dictionaries in one readable line |
| 5 | `05_functions.ipynb` | Write reusable functions with parameters, defaults, and return values |
| 6 | `06_modules_and_imports.ipynb` | Reuse standard-library code with `import` |
| 7 | `07_files_and_errors.ipynb` | Read and write files, and handle errors with `try` / `except` |

## Files in this folder

- `data/Text_File.txt` - a sample file used by the files lesson.
- `function_examples.ipynb` - a small runnable program that accompanies the functions lesson.

## How to work through a notebook

Read each section, run the example cells, and do the **Practice** before checking the
**Practice Solutions** at the bottom. When you are comfortable, move on to `03-advanced`.
