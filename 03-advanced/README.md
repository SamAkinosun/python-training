# Stage 3: Advanced

Object-oriented programming and the Python data stack: NumPy, pandas, and matplotlib.
This stage assumes you have finished the beginner and intermediate stages.

Before you start, make sure the data libraries are installed (from the project root):

```
pip install -r requirements.txt
```

## Lessons

| # | Notebook | You will be able to |
|---|----------|---------------------|
| 1 | `01_classes.ipynb` | Model things as classes with attributes, methods, and inheritance |
| 2 | `02_numpy.ipynb` | Use NumPy arrays for fast, loop-free numeric work |
| 3 | `03_pandas_intro.ipynb` | Build pandas Series and DataFrames, and load CSV files |
| 4 | `04_pandas_selecting_editing.ipynb` | Select, filter, add, and remove rows and columns |
| 5 | `05_pandas_analysis.ipynb` | Explore data with `describe`, `value_counts`, and `groupby` |
| 6 | `06_data_cleaning_and_combining.ipynb` | Handle missing values, fix types, and merge tables |
| 7 | `07_visualizing_data.ipynb` | Draw bar, line, and comparison charts from a DataFrame |
| 8 | `08_capstone_project.ipynb` | Put it all together in a short end-to-end analysis |

## Files in this folder

- `data/populations.csv` - sample data used by the pandas, visualisation, and capstone
  lessons.

## How to work through a notebook

Read each section and run the cells. In the capstone, try each step yourself before
opening the worked solution. Finish by running an analysis on a CSV from your own work.
